# Aisha Math ✨

Aventura interactiva de matemáticas para aprender jugando.

## Incluye

- 10 000 niveles generados de forma determinista.
- Perímetro, área, suma, resta, multiplicación, división, fracciones, geometría, patrones y problemas.
- Ejercicios visuales con rectángulos, cometas, cuadrículas, fracciones y grupos.
- Pistas progresivas y explicación paso a paso.
- Aisha lee ejercicios con voz del navegador en español.
- Respuesta por voz cuando el navegador soporta Web Speech Recognition.
- XP, rachas, progreso y reporte de habilidades.
- Progreso guardado localmente en el dispositivo, sin cuentas ni anuncios.
- Diseño responsive para celular, tablet y PC.

## Publicación

Este proyecto vive dentro del GitHub Pages principal en `/aisha-math/`.

## Estructura

- `index.html`: interfaz.
- `styles.css`: diseño y animaciones.
- `app.js`: generador de niveles, motor de juego, voz, pistas y progreso.
